## 1. Konsep 5W Spring Framework

- **What (Apa itu Spring?):**
  Spring Framework adalah framework open-source berbasis Java enterprise yang menyediakan infrastruktur menyeluruh untuk membangun aplikasi modern. Fitur intinya adalah Inversion of Control (IoC) dan Dependency Injection (DI) yang membuat kode menjadi modular dan mudah diuji.
- **Why (Mengapa menggunakan Spring?):**
  Memangkas penulisan kode repetitif (boilerplate), mempermudah pengelolaan siklus hidup komponen Java (Bean), serta memiliki ekosistem yang matang untuk web, sekuritas, dan basis data.
- **When (Kapan dibuat dan digunakan?):**
  Dibuat pertama kali pada tahun 2003 oleh Rod Johnson sebagai respons atas rumitnya arsitektur J2EE. Digunakan terutama ketika membangun backend web service, REST API, maupun arsitektur microservices enterprise.
- **Who (Siapa pembuat dan pengelolanya?):**
  Diarsiteki oleh Rod Johnson dan saat ini dikembangkan serta dikelola oleh VMware Tanzu.
- **Where (Di mana penerapannya?):**
  Diterapkan di layer backend/server-side untuk sistem perbankan, platform e-commerce, cloud services, dan backend API mobile/web skala enterprise.
